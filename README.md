# Pharmacy Store Management System

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Overview

This project is a **Pharmacy Store Management System** built to manage and track the full pharmacy workflow in a simple and efficient way.

It handles:

- Product management (add, update, stock tracking, categories)
- Receiving products from suppliers
- Issuing products to clients/customers
- Supplier management
- Client/customer management
- Stock movement tracking (in & out transactions)

The system is designed to work **offline locally**, making it reliable for pharmacies with limited or no internet access.

---

## Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **SQLite** (local database)
- Offline-first local storage approach
- Server-side API routes for data handling
